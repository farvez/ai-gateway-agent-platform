FastAPI · Multi-provider LLM

AI Gateway Agent Platform

One endpoint, any model. A unified API that routes chat requests to OpenAI, Anthropic Claude and Groq, returning the same response shape with token usage every time.

View on GitHub Quickstart

Features

Single /chat endpoint

Switch providers by changing one field in the request body.

Pluggable providers

Each backend implements an abstract LLMProvider. Adding one takes a single file.

Normalized responses

Same JSON schema across every provider: content, model and usage.

Token usage

Input, output and total tokens are reported on every call, ready for cost tracking.

Model overrides

Pick a specific model per request, or fall back to each provider's default.

OpenAPI docs

Interactive Swagger UI generated automatically at /docs.

Quickstart

git clone https://github.com/farvez/ai-gateway-agent-platform.git
cd ai-gateway-agent-platform
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # add your API keys
uvicorn app.main:app --reload

Example

POST /chat
{
  "provider": "claude",
  "message": "Explain vector DBs
              in one sentence.",
  "model": "claude-sonnet-5"
}
Response
{
  "provider": "anthropic",
  "model": "claude-sonnet-5",
  "content": "A vector database ...",
  "usage": {
    "input_tokens": 14,
    "output_tokens": 32,
    "total_tokens": 46
  }
}
